Meta Quest 3 専用 ／ シムコックピット向けパススルー

Sim Cockpit Passthrough

Meta Quest 3 専用の、シムコックピット向けパススルーアプリです。PC VR ゲームの上に、ハンドルやシフターなど、自分で選んだコックピットの実物だけを表示します。 見える範囲は自分で手で囲んで決められます。範囲は空間に貼り付くので、頭を動かしてもズレません。 ハンドルはステアリング範囲を設定すると、どれだけ回しても形どおりに見えます。 PC の VR ゲームを Quest に飛ばす「ALVR」をもとにした非公式の改造版です。

1Quest の設定（初回だけ）

範囲の編集はすべて手で行うので、Quest の 設定 → 動作（またはハンドトラッキング）で ハンドトラッキングとコントローラーとの自動切り替えを ON にしてください。

2Quest にアプリを入れる

最初に一度だけ、Quest の開発者モードを ON にします。 スマホの Meta Horizon アプリ → デバイス → ヘッドセットの設定 → 開発者モード。 「開発者組織の登録が必要」と出たら、案内どおり作成してください（無料・数分）。

あとはバッチをダブルクリックするだけです。

  1. zip をPC のローカルディスクに展開する（デスクトップなど。zip の中から直接は実行できません）
  2. 1_Questにインストール.bat をダブルクリック
  3. Quest を USB ケーブルで PC につなぐ
  4. ヘッドセットをかぶり、「USB デバッグを許可しますか？」が出たら 「このコンピューターから常に許可」にチェックして許可
  5. 黒い画面に「完了です」と出たら終わり。ケーブルは抜いて大丈夫です
Windows に「PC を保護しました」と出たら、詳細情報 → 実行を押してください。
公式の ALVR（ストア版・安定版・開発版）とは別のアプリなので、どれとも共存できます。
初回だけ、バッチが Quest との通信に使う adb（Google の Android SDK Platform-Tools r37.0.1）を Google の公式サイトから自動で取得します（約 8MB）。動作確認したのと同じ版を指定し、ファイルが改ざんされていないかも確かめてから使います。 取得したものは tools フォルダに置かれ、2回目からは取得しません。Google の利用規約が適用されます。
前の版「Cockpit Passthrough」を使っていた方へ
名前を「Sim Cockpit Passthrough」に変えたときに、中身は同じまま別のアプリになりました。 新しい版は古い版と並んで入り、作った範囲は引き継がれないので、作り直してください。 古い「Cockpit Passthrough」は、不要ならライブラリから削除してかまいません。
いつまでも「待っています…」のままのときは、ケーブルを挿し直す／別の USB ポートを試す／ Quest を再起動する、を試してください。充電専用のケーブルでは認識されません。

起動のしかた

Quest のライブラリを開き、右上のフィルタを 「提供元不明」 にすると 「Sim Cockpit Passthrough」があります。以降は PC につながなくても、ここから起動できます。

3PC の準備（初回だけ）

すでに ALVR を使っている場合は、SteamVR も設定もそのままで構いません。 やることは同梱のストリーマーに差し替えることだけです（下の 2. と 4.）。 バージョンが違うと接続できないため、ここだけは必須です。
  1. Steam から SteamVR をインストール（無料）
  2. pc/alvr_streamer_windows.zip を PC のローカルディスクに展開（例 C:\ALVR\）
    ネットワークドライブや USB メモリのままだと、SteamVR がドライバを読めないことがあります
  3. 展開したフォルダの ALVR Dashboard.exe を起動。初回のセットアップは「Next」で進めて OK、ファイアウォールの確認は「許可」
  4. 別バージョンの ALVR を使っていた場合は、Installation タブで古い ALVR ドライバを削除（Remove）
この改造版は開発版（v21.0.0-dev14）がベースです。公式の安定版 v20 系のストリーマーとは接続できません。必ず同梱の zip を使ってください。

4つなぐ

  1. PC で ALVR Dashboard.exe を起動しておく
  2. Quest で Sim Cockpit Passthrough を起動
  3. ダッシュボードの Devices タブに Quest が出てくるので Trust を押す
  4. SteamVR が自動で起動して映像が流れます（始まらなければ Launch SteamVR）
Settings → Video → Passthrough は OFF のままにしてください。
OFF＝このアプリの方式（囲んだ範囲だけが現実に見える）／ON＝ALVR 本来の全面パススルーに切り替わります。

USB ケーブルでつなぐ（有線接続）

Wi-Fi の代わりに、Quest とゲームを動かす PC を USB ケーブルでつないで映像を送ることもできます。 このアプリは公式の ALVR とアプリの名前（パッケージ名）が違うので、最初に一度だけダッシュボードの設定が必要です。

  1. ダッシュボードの Settings → Connection を開く
  2. Wired client type を Custom にして、名前の欄に app.simcockpit.passthrough と入力する
  3. Wired client autolaunch を ON にしておくと、つないだときにアプリが自動で起動します
  4. Devices タブの Wired Connection を ON にする
  5. Quest をゲームの PC に USB ケーブルでつなぐ。ヘッドセット内で「USB デバッグを許可」が出たら 「このコンピューターから常に許可」にチェックして許可
つながらないときは、データ通信できるケーブルか／Quest の開発者モードが ON か／SideQuest や Meta Quest Developer Hub を閉じたか／ Quest でアプリが前面に出ているか、を確かめてください。ダッシュボードの Devices タブに有線の Quest が「Disconnected」のまま出ている間は、まだつながっていません。

5基準アンカー（範囲の位置の基準）

範囲の位置は、部屋に置いた基準アンカー（空中の球）に対して覚えています。 アンカーは Quest 本体に保存され、起動するたびに自動で見つかるので、 再起動・被り直し・正面の再設定をしても、範囲は同じ場所に出ます。

  • 初回起動のとき、アンカーは目の前 30cm・少し上に自動で置かれ、そのときの正面を向きます。特に操作は要りません
  • アンカーの球は、編集モード中と、手の骨を表示しているときだけ見えます
  • 起動直後にアンカーを探している間は、範囲は表示されません。画面に Anchor: look around the room slowly と出たら、部屋をゆっくり見回してください（ふつうは一瞬で見つかります）
範囲の位置が実物から全体的にずれたときは、作り直さずに、編集モードでアンカーをつまんで動かすと 範囲全体をまとめて合わせられます（下の「アンカーで位置を合わせる」）。

6操作方法

操作はすべて手で行います。コントローラーを持っていても手は追跡され続けます。

左手のジェスチャー

手のひらを自分に向けると、手のひらの上にボタンが浮かびます。

開く（指を伸ばす） 編集メニューが出る
握る（こぶし） 中央＝範囲の表示／非表示の切り替え
右＝ゲーム中に手の骨の線（とアンカーの球）を表示／非表示
編集モード中は別のメニュー（下記）
その中間・手の甲 何も出ない（ハンドルを握った手で誤作動しないように）

ボタンは、右手の人差し指の先を当てて 0.35 秒ほど待つと作動します。待っている間、ボタンの周りを白いリングが一周します。

範囲の作り方

  1. 左手を開いて手のひらを向け、鉛筆マークのボタンに右手の人差し指を当てる → 編集モード開始。 編集中は全面が現実（パススルー）になり、実機を見ながら囲めます
  2. 右手の親指と人差し指をつまんで、見えるようにしたいものの縁をなぞる。 指どうしがほぼ触れるまでつまみ、0.35 秒ほど保つと描き始めます。5cm 進むごとに点が置かれ、線でつながります
  3. 形を直したいときは、下の表のとおりつまむ場所で動作が変わります
  4. 完了（青いチェック）を押すと保存され、囲んだ内側だけが現実に見える状態に戻ります。 次の起動時も同じ場所に出ます
保存されるのは「完了」を押したときだけです。
窓もステアリング範囲も、完了を押した時点の形と位置が保存され、次に起動したときに自動で出てきます。
編集モードのままアプリを終了したり、ヘッドセットを外してアプリが閉じたりすると、その回の編集は保存されません （前回完了した状態に戻ります）。編集が終わったら必ず完了を押してください。
新しい版をバッチで入れ直しても、保存した範囲は残ります。アプリをアンインストールすると消えます。

つまむ場所で動作が変わります

つまむ場所できること
点の上その点を移動（点はほぼ重なるまで近づけてください）
枠線の上（点から離れた所）そこに点を追加して、そのまま動かせます
範囲の内側形を変えずに範囲ごと移動（パン）
どの範囲からも離れた所新しい範囲を描き始めます

点が増えていくのは新規に描いているときだけです。移動のつまみで勝手に点が増えることはありません。 別の範囲を編集したいときは、その範囲の点や内側をつまむと切り替わります。 切り替えた最初のつまみでは何も動きません（点が動いてしまうのを防ぐため）。もう一度つまむと編集できます。 編集中の範囲は明るい緑の太線と大きな点、それ以外は暗い細線で表示されます。

きれいに見せるコツ: 実機（ハンドルやシフター）に触れながらなぞってください。 カメラ映像は作った面に投影されるので、面が実機の奥行きに沿っているほど自然に見えます。 一周しなくても、最後の点と最初の点は自動でつながります。

左手のボタン（編集中）

上／ステアリング範囲を追加（下記）
右／完了（保存して終了）
左／元に戻す
中央（ゴミ箱）／3 通りの削除。 点をつまんで運んで離す＝その点を削除／ 範囲の内側をつまんで運んで離す＝その範囲を削除／ 指先を当てて待つ＝最後に触った範囲を削除

左手のボタン（編集中に握ったとき）

  • 右（球のアイコン）／アンカーの位置の設定（下の「アンカーの位置を設定し直す」）
  • 左（×）／全範囲を削除。誤操作防止のため1.2 秒の長押し。 アンカーも目の前 30cm・少し上に置き直され、そのときの正面を向きます。元に戻せません

アンカーで位置を合わせる（編集モード中）

編集モード中は、アンカーの球の周りに3 本の輪（赤・緑・青）が出ます。 アンカーを動かすと、範囲とステアリング範囲もまとめて一緒に動くので、実物に合わせ直すのに使います。

  1. アンカーを一度つまむと選択されます（輪が明るくなる。まだ動きません）
  2. 選択中に、中心の球をつまんで動かすと移動、輪をつまんで輪に沿って回すとその軸で回転
  3. アンカー以外の場所をつまむと選択が解除されます（このつまみでは範囲は描かれません）
  4. 元に戻すで 1 回ずつ戻せます。完了で確定・保存されます

アンカーの位置を設定し直す（範囲は動かさない）

範囲はそのままで、基準の球だけを置き直したいときに使います（範囲がたくさんある場所の近くに置くと、ずれにくくなります）。

  1. 編集モードで左手を握り、右の球のアイコンを押す
  2. 球の中心をつまんで、置きたい場所へ動かす
  3. 左手の 右（✓）で設定、左で 1 つ前に戻る、下（×）で取り消し（左手は開いても握ったままでも出ます）
  4. 設定したときの顔の正面の向きがアンカーの向きになります。範囲は現実の位置のまま動きません

ステアリング範囲の設定

ハンドルは回すと見え方が変わるので、手で囲む窓ではなくステアリング範囲で設定します。 ハンドルが回る範囲を円柱の形で指定すると、その中にあるハンドルと握った手だけが見えるようになります。 どれだけ回しても形どおりに見えます。丸型・フォーミュラ型どちらでも使えます。 スポークのすき間など、ハンドルの向こうが見通せる所はゲームのまま表示するので、メーターが隠れません。

  1. 編集モードで、左手のボタンの上（オレンジ）を押す。目の前にオレンジの円柱が出ます
  2. 円柱の中心の軸を、ハンドルの回転軸（ステアリングシャフト）に合わせます。 軸の両端の緑の印をつまんで動かすと、軸の向きと厚みが変わります。 手前の印をハンドルの手前側、奥の印をハンドルの奥側に置いて、軸がハンドルの中心を貫くようにします
  3. 外周のオレンジの印をつまんで、半径をハンドルの外周より少しだけ大きくします
  4. 円柱の内側をつまむと、形を変えずにまるごと動かせます
  5. 完了で編集モードを抜けると、範囲の中のハンドルが見えるようになります。このとき窓と一緒に保存されます

編集モード中は、範囲の中で見えるようになる物が水色に塗られます。 この水色の形が、そのままゲーム中に見える形です。 ハンドルを端から端まで回して、ずっと水色のままかを確かめてください。

軸がハンドルの回転軸からずれていると、回したときにハンドルの一部が範囲からはみ出して欠けます。 回転軸に合わせるのが一番大事です。
円柱の中にある物は余白なしでそのまま取り込み、外にある物は取り込みません。 厚みは、ハンドル・パドル・握った手が入るくらいにします。厚くしすぎると、奥のレバーやハンドルコントローラー本体、モニターまで見えてしまいます。 見せたくない物が水色になっていたら、円柱を小さく・薄くしてください。

ステアリング範囲も窓と同じように、つまむと選択され、ゴミ箱で削除でき、全削除でも消えます。 シフターやボタンボックスは、今までどおり手で囲む窓を使ってください（ステアリング範囲と同時に使えます）。

手とコントローラーの扱い

このアプリは範囲の編集のために常に手を追跡していますが、 手の情報はゲーム（SteamVR）には送っていません。 ゲーム中に手が勝手にコントローラー扱いされて誤操作になるのを防ぐためです。 コントローラーは今までどおりそのまま使えます。

  • 手の骨の線は編集モード中に出ます。それ以外では、左手のこぶしの右ボタンで表示／非表示を切り替えられます（起動時は非表示）
  • 編集モード中は、コントローラーの入力もゲームに送られません（なぞる動作がトリガー連打になるのを防ぐため）
  • あえて手をゲームの入力に使いたい場合は、ダッシュボードの Settings → Headset → Tracking → Multimodal tracking を ON にしてください （変更後は SteamVR の再起動が必要）

黒いハンドルの一部が抜ける黒くてつやのある素材は捉えにくく、大きな面だと抜けることがあります
SteamVR にコントローラーが出ないコントローラーの電源とペアリングを確認。ダッシュボードの Devices タブで接続中か確認してください

8今の制限（テスト版）

  • 基準アンカーは Quest の部屋の記憶に結び付いています。シミュレーターを部屋の中で動かした場合や、 部屋のセットアップをやり直した場合は、編集モードでアンカーを動かして範囲を合わせ直してください
  • 範囲が見えるのはこのアプリの中だけです。Quest のホーム画面や他のアプリには出せません
  • カメラ映像は作った面に投影されるため、面から離れた物ほど平たく（写真のように）見えます
  • 手の情報はゲームに送っていないので、ハンドトラッキング前提のゲームは操作できません （上記の Multimodal tracking を ON にすれば使えます）
  • ステアリング範囲は、ハンドルを素早く回すと縁がわずかに遅れて付いてきます。回した直後に、前の位置の形が一瞬残ることがあります
  • ステアリング範囲の縁は実物の輪郭で切りますが、深度センサーの精度の都合で数 mm ほど揺れたり、にじんだりすることがあります
  • ステアリング範囲は、目から約20cmより近い物や、黒くてつやのある物・金属・ガラスが苦手です
  • Meta Quest 3 専用です（Quest 2 などではステアリング範囲が使えません）
